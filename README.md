# 💄 올리브영 가격 및 가성비(단위가격) 추적 대시보드
(Olive Young Price & Unit Price Tracker)

올리브영 주요 카테고리의 랭킹 상품(TOP 100) 및 사용자가 직접 등록한 제품들의 가격을 매일 자동으로 수집하여, **가격 변동 추이**, **역대 최저가 분석**, **단위 용량당(10ml/10g/1매) 가성비 비교**를 제공하는 초고속 정적 웹 대시보드입니다.

👉 **[웹사이트 바로가기 (대시보드 접속)](https://soyeone.github.io/trackingPrice/)**

---

## 🚀 사용자 가이드 (How to Use)

### 1. 📊 가격 및 가성비 한눈에 보기
웹사이트에 접속하면 카테고리별로 분류된 상품 목록이 즉시 표시됩니다.
* **배지 확인**: 랭킹 진입 상품(`관련 카테고리 n위`), 직접 등록한 상품(`📌 직접 등록`), 판매 종료된 상품(`⛔ [판매종료]`)을 배지로 직관적으로 구분할 수 있습니다.
* **가성비 정렬**: 우측 상단의 정렬 버튼을 통해 `👑 랭킹순`, `⚡ 가성비순(단위가격 낮은 순)`, `📉 가격순(단순 가격 낮은 순)`으로 즉시 재정렬하여 진짜 저렴한 기획 세트를 찾아낼 수 있습니다.

### 2. 📈 과거 가격 추이 및 역대 최저가 확인
상품 카드를 클릭하면 상세 차트 페이지로 이동합니다.
* **인터랙티브 차트**: 수집된 기간 동안의 일자별 가격 변동 그래프를 한눈에 볼 수 있습니다.
* **최저가 알림**: 현재 가격이 역대 최저가인지, 아니면 최저가 대비 얼마나 비싸졌는지를 색상과 함께 명확하게 알려줍니다.
* **단위 가격 정보**: 단순 판매가가 아닌, 기획세트(1+1, 더블기획, 증정품 등)의 총 용량을 계산한 '단위 용량당 진짜 가격'을 확인할 수 있습니다.

### 3. ➕ 추적하고 싶은 새 제품 등록하기
올리브영에서 사고 싶은 상품을 발견했다면 트래커에 추가하여 내일부터 가격 변동을 감시할 수 있습니다.
1. 상단 메뉴의 **[새 제품 등록]** 탭으로 이동합니다.
2. 추적하고 싶은 올리브영 상품의 URL 주소(링크)를 복사하여 입력합니다.
3. **[등록하고 즉시 트래킹 시작]** 버튼을 누릅니다.
4. **반영 안내**: 등록된 상품은 데이터베이스에 안전하게 저장되며, **다음 번 크롤러가 작동할 때(통상 다음 날 아침) 정적 데이터로 구워져 웹사이트 대시보드에 나타나게 됩니다.** (즉시 반영을 원할 경우 로컬 PC에서 크롤러를 수동 실행하면 됩니다.)

## ⚙️ 시스템 작동 방식 (데이터 업데이트)

본 프로젝트는 서버 유지비가 전혀 들지 않으면서도 로딩 속도를 극한으로 끌어올린 **Ultimate Jamstack (정적 JSON 분할 로딩) 아키텍처**를 사용합니다.

1. **자동 수집 (크롤러 작동)**
   - 지정된 로컬 PC에서 매일 자동(또는 `run_daily_scraper.bat` 수동 실행)으로 올리브영 가격을 수집합니다.
   - 새로 랭킹에 진입한 상품은 자동 추가되며, 랭킹에서 밀려난 상품도 계속 추적합니다.
2. **데이터 베이킹 및 분할 배포**
   - 수집이 끝나면 DB에서 최신 데이터를 끌어와 상품별로 초경량 JSON 파일(수천 개)로 쪼개어 생성한 뒤, GitHub 저장소에 자동 Push 합니다.
3. **초고속 웹 렌더링 및 지연 로딩 (Lazy Loading)**
   - 사용자가 사이트에 접속할 때는 50KB 미만의 최소 데이터만 받아 **0초 대에 즉각 화면을 띄웁니다.**
   - 상품을 클릭하는 순간에만 해당 상품의 과거 데이터 기록(1~2KB)을 백그라운드에서 다운로드하여 차트를 그리기 때문에, 수년 치 데이터가 수백만 건 쌓여도 웹사이트가 전혀 느려지지 않습니다.
