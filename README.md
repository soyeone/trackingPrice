# 💄 올리브영 가격 및 가성비(단위가격) 자동 트래킹 대시보드
(Olive Young Price & Unit Price Tracker)

올리브영 주요 12개 카테고리의 랭킹 상품(TOP 100) 및 사용자가 등록한 제품의 일자별 가격을 자동으로 추적하여, **가격 변동 추이**, **역대 최저가/최고가 분석**, **10ml당/개당 단위가격 기반 가성비 비교**를 제공하는 대시보드입니다.

---

## 🚀 빠른 시작 (Quick Start)

### 1. 로컬 대시보드 및 실시간 등록 서버 실행
```bash
npm start
# 또는 node server.js
```
* **대시보드**: [http://localhost:3000/index.html](http://localhost:3000/index.html)
* **새 제품 등록**: [http://localhost:3000/register.html](http://localhost:3000/register.html)

### 2. 터미널에서 상품 즉시 등록 및 가격 트래킹
```bash
# Node.js 사용 시
npm run track "https://www.oliveyoung.co.kr/store/goods/getGoodsDetail.do?goodsNo=A000000262602"

# Python 사용 시
python scraper/main.py A000000262602
```

### 3. 전체 카테고리 랭킹 스크래핑 수동 실행
```bash
cd scraper
python main.py
```
*(GitHub Actions를 통해 매일 아침 09:00 KST에 자동으로도 실행됩니다)*

## 🌟 주요 기능

1. **12개 카테고리 실시간 랭킹 트래킹**: 스킨케어, 마스크팩, 클렌징, 선케어 등 카테고리별 상위 100개 상품 가격 일일 추적
2. **신규 진입 상품 자동 등록 & 랭킹 밖 상품 지속 추적**: 순위 변동이 있어도 데이터 유실 없이 지속적으로 가격 기록 누적
3. **정량 규격 기반 단위가격 산출**:
   - 액체류(`ml`, `L`): **10ml당 가격** (1+1, 더블기획, 리필기획 합산 반영)
   - 크림/파우더류(`g`, `kg`): **10g당 가격**
   - 마스크팩/패드류(`매`): **1매당 가격**
   - 영양제/소품류(`정`, `포`, `개`): **개/정/포당 가격**
4. **가성비 정렬 모드**: `👑 랭킹순`, `⚡ 가성비순 (단위가격 낮은순)`, `📉 가격순` 즉시 비교
5. **인터랙티브 일자별 가격 변동 차트**: Chart.js 기반 시각화 및 역대 최저가/최고가 대비 변동률 표시
6. **새 제품 등록 즉시 트래킹**: URL 등록 즉시 실시간 상품명/가격 수집 및 당일 가격 기록
